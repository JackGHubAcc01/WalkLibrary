TRAILATLAS V0.3

Ground-up redesign of WalkLibrary.

- Opens directly to a world map.
- Starter catalogue of 20 major international long-distance trails.
- Search worldwide trails.
- Save trails.
- Plan future trips.
- Store hotel, campsite/refuge, flight, train, bus, ferry, parking, permit and other bookings against a trip.
- PWA/local storage retained.

Important:
Trail points and headline metadata in this prototype are discovery/demo data, not navigation data. They must be verified before production use.
V0.3 does not yet contain verified GPX route lines.
Base map requires internet.
Booking import is currently structured manual entry; automatic email/PDF/screenshot extraction is not yet implemented.
